CORE CONCEPTS

Sample Space & Events

Ω

Sample Space

A collection of all elementary results, or outcomes of an experiment.

E

Event

Any set of outcomes. Events are subsets of the sample space. N outcomes yield 2^N events.

P(E)

Probability

A number between 0 and 1 measuring how likely an event is. P{E} = probability of event E.

Ā

Complement

All outcomes not in event A. Notation: Ā or A^c.   P(Ā) = 1 − P(A)

Example 1: A tossed die produces 6 possible outcomes: 1 through 6 dots.  Ω = {1,2,3,4,5,6}. E = "even" = {2,4,6}. P(E) = 3/6 = 0.5.

CORE CONCEPTS

Set Operations & Event Types

Union A ∪ B

All outcomes in A or B (or both).

Intersection A ∩ B

Outcomes in both A and B.

Disjoint / Mutually Exclusive

A ∩ B = ∅. Events cannot happen together. A_i ∩ A_j = ∅ for any i ≠ j.

Exhaustive Events

A ∪ B ∪ C ∪ … = Ω. They cover all possible outcomes.

De Morgan's Laws

A∪B = Ā ∩ B̅    and    A∩B = Ā ∪ B̅

Complement & Difference

Ā or A^c = complement.   A \ B = difference.

Example 2: Receiving a grade of A, B, or C for some course are mutually exclusive events, but unfortunately, they are not exhaustive.

RULES

Rules of Probability

1. Unit Measure

P(Ω) = 1

2. Sigma-Additivity

P(∪Eᵢ) = Σ P(Eᵢ)

3. Complement

P(Ā) = 1 − P(A)

4. Union (Inclusion–Exclusion)

P(A∪B) = P(A)+P(B)−P(A∩B)

5. Conditional

P(A|B) = P(A∩B) / P(B)

6. Multiplication

P(A∩B) = P(A|B)×P(B)

7. Law of Total Prob.

P(A) = Σ P(A|Bᵢ)×P(Bᵢ)

8. Bayes' Rule

P(B|A) = P(A|B)×P(B)/P(A)
EXAMPLE 4

Hard Drive Crash Probability

Problem

There is a 1% probability for a hard drive to crash. It has two backups, each having a 2% probability to crash.

All three components are independent of each other.

The stored information is lost only when all three devices crash.

What is the probability that the information is saved?

Solution

P(crash) = 0.01, P(backup1 crash) = 0.02, P(backup2 crash) = 0.02. Independent.

P(lost) = 0.01 × 0.02 × 0.02 = 0.000004

P(saved) = 1 − 0.000004 = 0.999996

Answer: 99.9996% probability

EXERCISE 1

Flight Departures & Arrivals

90% of flights depart on time. 80% arrive on time. 75% depart AND arrive on time.

a You meet a flight that departed on time. P(it arrives on time)?

b You meet a flight that arrived on time. P(it departed on time)?

c Are "depart on time" and "arrive on time" independent?

SOLUTION 1

Flight Departures & Arrivals — Answer

Given: P(D) = 0.90, P(A) = 0.80, P(D∩A) = 0.75

(a) P(A | D) — Conditional

= P(D∩A) / P(D) = 0.75 / 0.90 = 0.8333

(b) P(D | A) — Conditional

= P(D∩A) / P(A) = 0.75 / 0.80 = 0.9375

(c) Independence check

P(D)×P(A) = 0.90×0.80 = 0.72  ≠  P(D∩A) = 0.75

Not independent

EXERCISE 2

Viral Infection Test

A test is 95% reliable for infected patients and 99% reliable for healthy ones. 4% of patients are infected.

a If the test shows positive, what is P(patient has the virus)?

b If the test shows negative, what is P(patient is healthy)?

SOLUTION 2

Viral Infection Test — Answer

Let V = "has virus", T+ = "test positive".

Given: P(V)=0.04, P(T+|V)=0.95, P(T+|V̅)=0.01

(a) P(V|T+) — Bayes' Rule

= (0.95×0.04) / (0.95×0.04 + 0.01×0.96) = 0.038 / 0.0476 ≈ 0.7983
≈ 79.83% probability

(b) P(V̅|T−) — Bayes' Rule

= (0.99×0.96) / (0.99×0.96 + 0.05×0.04) = 0.9504 / 0.9524 ≈ 0.9979
≈ 99.79% probability

ASSIGNMENT

Unsigned Exam Papers

Students X, Y, Z forgot to sign their papers. Prof knows they write a good exam with probabilities:

X: 0.8 Y: 0.7 Z: 0.5

1 After grading, two exams are good and one is bad. What are the possible assignments?

2 P(bad exam belongs to Z | two good, one bad)?

3 P(bad exam belongs to X)?

4 Which student is most likely to have written the bad exam?

ASSIGNMENT SOLUTION

Unsigned Exam Papers — Answer

P(X good)=0.8, P(Y good)=0.7, P(Z good)=0.5. Independent. Two good, one bad.

P(evidence) = 0.2×0.7×0.5 + 0.3×0.8×0.5 + 0.5×0.8×0.7 = 0.07 + 0.12 + 0.28 = 0.47

1. Possible assignments

3 possibilities: (X bad, Y+Z good), (Y bad, X+Z good), (Z bad, X+Y good)

2. P(X bad | evidence)

= 0.2×0.7×0.5 / 0.47 = 0.07/0.47 ≈ 0.1489

3. P(Y bad | evidence)

= 0.3×0.8×0.5 / 0.47 = 0.12/0.47 ≈ 0.2553

4. Most likely

P(Z bad) = 0.5×0.8×0.7 / 0.47 = 0.28/0.47 ≈ 0.5957

Z is most likely (59.57%)

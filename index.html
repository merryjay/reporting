CORE CONCEPTS

Sample Space & Events

Ω

Sample Space

The set of every possible outcome of an experiment — nothing is left out.

Ω = {ω₁, ω₂, ..., ωₙ}
E

Event

Any subset of the sample space — a group of outcomes we care about.

E ⊆ Ω  ·  N outcomes → 2ᴺ events
P(E)

Probability

A number between 0 and 1 measuring how likely an event is to occur — 0 = impossible, 1 = certain.

P : 𝔐 → [0, 1]  ·  P{E} = probability of E
Ā

Complement

All outcomes NOT in event A — the opposite of the event occurring.

Ā = {x | x ∉ A}  ·  P(Ā) = 1 − P(A)

Example 1: A tossed die produces 6 possible outcomes: 1 through 6 dots.  Ω = {1,2,3,4,5,6}. E = "even" = {2,4,6}. P(E) = 3/6 = 0.5.

CORE CONCEPTS

Probability — Definition & Meaning

Definition

Probability is a number assigned to an event that measures how likely it is to occur. It is a function that maps events to values between 0 and 1.

P : 𝔐 → [0, 1]

What It Means

A probability of 0 means the event is impossible — it will never happen. A probability of 1 means the event is certain — it will always happen. Values in between represent varying degrees of likelihood.

0 ≤ P(E) ≤ 1  ·  P(Ω) = 1  ·  P(∅) = 0

Classical Formula

When all outcomes are equally likely, the probability of an event is the ratio of favorable outcomes to total possible outcomes.

P(E) = |E| / |Ω| = favorable / total

Example: Rolling a die, P(even) = 3/6 = 0.5

Intuition

Probability quantifies uncertainty — it tells us how frequently we expect an event to occur if we repeated the experiment many times. The closer to 1, the more likely the event.

P(E) = 1 → always happens  ·  P(E) = 0 → never happens

CORE CONCEPTS

Set Operations & Event Types

Union A ∪ B

All outcomes that belong to A or B (or both) — an outcome counts if it is in at least one of the two events.

A ∪ B = {x | x ∈ A ∨ x ∈ B}

Intersection A ∩ B

Only the outcomes that belong to both A and B — they must overlap for an outcome to count.

A ∩ B = {x | x ∈ A ∧ x ∈ B}

Disjoint / Mutually Exclusive

Events that never overlap — if one happens, the other cannot possibly happen at the same time.

A ∩ B = ∅  ·  Aᵢ ∩ Aⱼ = ∅ for i ≠ j

Exhaustive Events

A group of events that together cover every possible outcome — at least one of them must occur.

A ∪ B ∪ C ∪ … = Ω

De Morgan's Laws

Law 1: Not in (A or B) = Not in A and not in B — the complement of a union is the intersection of complements.

A ∪ B = Ā ∩ B̅

Law 2: Not in (A and B) = Not in A or not in B — the complement of an intersection is the union of complements.

A ∩ B = Ā ∪ B̅

Complement & Difference

Complement: Everything the event is NOT — the opposite of the event.

Ā = Aᶜ = {x | x ∉ A}

Difference: Outcomes that are in A but not in B — removing B's outcomes from A.

A \ B = {x | x ∈ A ∧ x ∉ B}

Example 2: Receiving a grade of A, B, or C for some course are mutually exclusive events, but unfortunately, they are not exhaustive.

EXAMPLE 1

Tossed Die Experiment

Problem

A tossed die can produce one of 6 possible outcomes: 1 dot through 6 dots.

Each outcome is an event. There are also other events like observing an even number, an odd number, or a number less than 3.

List all possible events and identify the sample space.

Solution

Sample space: Ω = {1, 2, 3, 4, 5, 6}

Possible events: Eeven = {2,4,6}, Eodd = {1,3,5}, E<3 = {1,2}

A sample space of 6 outcomes yields 26 = 64 possible events.

P(E) = |E| / |Ω| = favorable / total

Each outcome is equally likely → P(even) = 3/6 = 0.5, P(odd) = 3/6 = 0.5, P(<3) = 2/6 ≈ 0.33

Ω has 6 outcomes → 64 possible events

EXERCISE 1

Coin Toss Experiment

A fair coin is tossed twice. Consider the sample space of all possible outcomes.

a Write the sample space Ω for two coin tosses.

The sample space lists every possible sequence — each toss has 2 outcomes (H or T), so there are 2 × 2 = 4 equally likely outcomes.

b Let A = "at least one head". List the outcomes in A.

A is the event containing all outcomes where at least one H appears — meaning 1 or 2 heads, but not zero heads.

c Let B = "both tosses are the same". List the outcomes in B. Find A ∩ B.

A ∩ B finds outcomes where both conditions are true at once — intersection means they must satisfy both "at least one head" AND "both tosses are the same".

✅
SOLUTION 1

Coin Toss Experiment — Answer

Given: A fair coin tossed twice. Each toss: H (heads) or T (tails).

(a) Sample Space

Ω = {HH, HT, TH, TT}

4 possible outcomes yield 24 = 16 possible events.

Meaning: The sample space contains all 4 possible sequences of two coin flips — each sequence is equally likely since the coin is fair.

(b) Event A = "at least one head"

A = {HH, HT, TH}

Meaning: A includes every outcome with at least one H — the only outcome left out is TT (no heads at all).

(c) B = "both tosses same" and A ∩ B

B = {HH, TT},   A ∩ B = {HH}

Meaning: B contains outcomes where both tosses match. A ∩ B = {HH} is the only outcome that satisfies both "at least one head" AND "both tosses the same" — intersection finds common ground.

EXERCISE 2

Card Draw Event Types

A single card is drawn from a standard 52-card deck. Consider these events:

A = "draw a heart",   B = "draw a face card (J, Q, K)",   C = "draw a red card"

a Are A and C mutually exclusive? Justify.

Mutually exclusive means no overlap — can a single card be both a heart AND red? If they share any outcomes, they are NOT mutually exclusive.

b Are A and B exhaustive? Find A ∪ B.

Exhaustive means covering the entire deck — does A ∪ B include all 52 cards? If any card is neither a heart nor a face card, they are NOT exhaustive.

c Find A ∩ B and A \ B using set difference.

A ∩ B = outcomes that are in BOTH A and B. A \ B = outcomes in A but NOT in B — remove the face cards from the hearts.

✅
SOLUTION 2

Card Draw Event Types — Answer

Given: Standard 52-card deck. A = hearts, B = face cards, C = red cards.

(a) Mutually exclusive check

Hearts are red, so A ∩ C = A ≠ ∅.   Not mutually exclusive

Meaning: Hearts are a subset of red cards (all hearts are red). Since they share outcomes (every heart is also a red card), A and C overlap — they are NOT mutually exclusive.

(b) Exhaustive check & A ∪ B

A ∪ B = {all hearts} ∪ {face cards} ≠ Ω

Not exhaustive — many cards are neither hearts nor face cards.

Meaning: A ∪ B includes hearts plus face cards from all suits, but there are still many cards that are neither (e.g., 2♠, 5♦, 9♣). Since A ∪ B ≠ Ω, they are NOT exhaustive.

(c) A ∩ B and A \ B

A ∩ B = {heart face cards}  |  A \ B = {non-face hearts}

Meaning: A ∩ B = heart face cards — cards that are BOTH hearts AND face cards (J♥, Q♥, K♥). A \ B = hearts that are NOT face cards — removing face cards from hearts leaves ranks 2–10 + A♥.

ASSIGNMENT

Rolling Two Dice

Two fair dice are rolled. Consider these events:

A: sum = 7 B: sum = 11 C: both dice show the same number

1 Write the sample space Ω. How many outcomes?

Each die has 6 faces, so the sample space is all ordered pairs (die1, die2) — 6 × 6 = 36 equally likely outcomes.

2 List outcomes in A, B, and C. Are A and B mutually exclusive?

Mutually exclusive means no overlap — can a single roll sum to both 7 AND 11? If A ∩ B = ∅, they are mutually exclusive.

3 Find A ∪ C. Are A and C exhaustive?

Exhaustive means covering all 36 outcomes — does A ∪ C contain every possible roll? If any outcomes are missing, they are not exhaustive.

4 Find Ā (complement of A), verify De Morgan's: Ā∩B = Ā ∪ B̅

Ā = everything that is NOT a sum of 7. De Morgan's Law 1 says "not in (A or B) = not in A and not in B" — verify by computing both sides.

🏆
ASSIGNMENT SOLUTION

Rolling Two Dice — Answer

Given: Two fair dice rolled. Each die: 1-6. Outcomes are ordered pairs (die1, die2).

1. Sample Space

Ω = {(1,1)...(6,6)}   6×6 = 36 outcomes

Meaning: Each die has 6 faces, so 6 × 6 = 36 equally likely ordered pairs — every combination of die1 and die2 is a possible outcome.

2. A, B, C & mutual exclusion

A = {(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)}   B = {(5,6),(6,5)}   C = {(1,1)...(6,6)}

A ∩ B = ∅ → Mutually exclusive

Meaning: A (sum=7) has 6 outcomes and B (sum=11) has 2 outcomes. They share no outcomes — no single roll can sum to both 7 and 11, so A ∩ B = ∅.

3. A ∪ C & exhaustive check

A ∪ C has 6 + 6 − 1 = 11 outcomes (sum=7 overlap with doubles at none). Not exhaustive since 36 − 11 = 25 outcomes missing.

Meaning: A ∪ C combines sum=7 outcomes (6) with doubles (6) — no overlap since no double sums to 7. Only 11 out of 36 outcomes are covered, so 25 are missing — NOT exhaustive.

4. Complement & De Morgan's

Ā = outcomes where sum ≠ 7 (30 outcomes). Ā∩B = Ā ∪ B̅ = complement of all outcomes where sum=7 or sum=11.

Meaning: Ā = everything NOT in A (all 36 outcomes minus the 6 that sum to 7 = 30 outcomes). De Morgan's Law 1: Ā∩B = Ā ∪ B̅ — "not in (A or B)" equals "not in A and not in B", verified by computing both sides.

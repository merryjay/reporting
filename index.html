CORE CONCEPTS

Sample Space & Events

Ω

Sample Space

A collection of all elementary results, or outcomes of an experiment.

E

Event

Any set of outcomes. Events are subsets of the sample space. N outcomes yield 2^N events.

P(E)

Probability

A number between 0 and 1 measuring how likely an event is. P{E} = probability of event E.

Ā

Complement

All outcomes not in event A. Notation: Ā or A^c.   P(Ā) = 1 − P(A)

Example 1: A tossed die produces 6 possible outcomes: 1 through 6 dots.  Ω = {1,2,3,4,5,6}. E = "even" = {2,4,6}. P(E) = 3/6 = 0.5.

CORE CONCEPTS

Set Operations & Event Types

Union A ∪ B

All outcomes in A or B (or both).

Intersection A ∩ B

Outcomes in both A and B.

Disjoint / Mutually Exclusive

A ∩ B = ∅. Events cannot happen together. A_i ∩ A_j = ∅ for any i ≠ j.

Exhaustive Events

A ∪ B ∪ C ∪ … = Ω. They cover all possible outcomes.

De Morgan's Laws

A∪B = Ā ∩ B̅    and    A∩B = Ā ∪ B̅

Complement & Difference

Ā or A^c = complement.   A \ B = difference.

Example 2: Receiving a grade of A, B, or C for some course are mutually exclusive events, but unfortunately, they are not exhaustive.

EXAMPLE 1

Tossed Die Experiment

Problem

A tossed die can produce one of 6 possible outcomes: 1 dot through 6 dots.

Each outcome is an event. There are also other events like observing an even number, an odd number, or a number less than 3.

List all possible events and identify the sample space.

Solution

Sample space: Ω = {1, 2, 3, 4, 5, 6}

Possible events: Eeven = {2,4,6}, Eodd = {1,3,5}, E<3 = {1,2}

A sample space of 6 outcomes yields 26 = 64 possible events.

EXERCISE 1

Coin Toss Experiment

A fair coin is tossed twice. Consider the sample space of all possible outcomes.

a Write the sample space Ω for two coin tosses.

b Let A = "at least one head". List the outcomes in A.

c Let B = "both tosses are the same". List the outcomes in B. Find A ∩ B.

SOLUTION 1

Coin Toss Experiment — Answer

Given: A fair coin tossed twice. Each toss: H (heads) or T (tails).

(a) Sample Space

Ω = {HH, HT, TH, TT}

4 possible outcomes yield 24 = 16 possible events.

(b) Event A = "at least one head"

A = {HH, HT, TH}

(c) B = "both tosses same" and A ∩ B

B = {HH, TT},   A ∩ B = {HH}

EXERCISE 2

Card Draw Event Types

A single card is drawn from a standard 52-card deck. Consider these events:

A = "draw a heart",   B = "draw a face card (J, Q, K)",   C = "draw a red card"

a Are A and C mutually exclusive? Justify.

b Are A and B exhaustive? Find A ∪ B.

c Find A ∩ B and A \ B using set difference.

SOLUTION 2

Card Draw Event Types — Answer

Given: Standard 52-card deck. A = hearts, B = face cards, C = red cards.

(a) Mutually exclusive check

Hearts are red, so A ∩ C = A ≠ ∅.   Not mutually exclusive

(b) Exhaustive check & A ∪ B

A ∪ B = {all hearts} ∪ {face cards} ≠ Ω

Not exhaustive — many cards are neither hearts nor face cards.

(c) A ∩ B and A \ B

A ∩ B = {heart face cards}  |  A \ B = {non-face hearts}

ASSIGNMENT

Rolling Two Dice

Two fair dice are rolled. Consider these events:

A: sum = 7 B: sum = 11 C: both dice show the same number

1 Write the sample space Ω. How many outcomes?

2 List outcomes in A, B, and C. Are A and B mutually exclusive?

3 Find A ∪ C. Are A and C exhaustive?

4 Find Ā (complement of A), verify De Morgan's: Ā∩B = Ā ∪ B̅

ASSIGNMENT SOLUTION

Rolling Two Dice — Answer

Given: Two fair dice rolled. Each die: 1-6. Outcomes are ordered pairs (die1, die2).

1. Sample Space

Ω = {(1,1)...(6,6)}   6×6 = 36 outcomes

2. A, B, C & mutual exclusion

A = {(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)}   B = {(5,6),(6,5)}   C = {(1,1)...(6,6)}

A ∩ B = ∅ → Mutually exclusive

3. A ∪ C & exhaustive check

A ∪ C has 6 + 6 − 1 = 11 outcomes (sum=7 overlap with doubles at none). Not exhaustive since 36 − 11 = 25 outcomes missing.

4. Complement & De Morgan's

Ā = outcomes where sum ≠ 7 (30 outcomes). Ā∩B = Ā ∪ B̅ = complement of all outcomes where sum=7 or sum=11.
